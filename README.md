# 🐾 Patte Solidaire

## 📖 Description

Patte Solidaire est un site web dédié à la protection et au bien-être des animaux.

L'objectif du projet est de proposer une plateforme permettant aux visiteurs de découvrir les actions de l'association, consulter les actualités, signaler un animal en difficulté et contacter l'association.

Le projet contient également un espace d'administration permettant de gérer les actualités, les messages et les paramètres du site.

## ✨ Fonctionnalités

### 👤 Espace utilisateur

- 🏠 Page d'accueil
- ℹ️ Présentation de l'association
- 🐾 Informations sur la protection des animaux
- 🚑 Signaler un animal blessé ou en difficulté
- 📰 Consulter les actualités
- 📩 Contacter l'association
- 👤 Profil

### 🔐 Espace administrateur

- 🔑 Connexion administrateur
- 📊 Dashboard
- 📰 Gestion des actualités
- 📩 Gestion des messages
- ⚙️ Gestion des paramètres
- 🐾 Consultation des signalements d'animaux

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub

## 💾 Gestion des données

Les données du projet sont stockées localement dans le navigateur grâce à `localStorage`.

Cette solution est utilisée dans le cadre de ce projet frontend afin de simuler la gestion des données sans utiliser de base de données externe.

## 🎯 Objectif du projet

Ce projet a été réalisé dans le but de mettre en pratique les compétences en développement web frontend, notamment :

- La création de pages web avec HTML
- La mise en forme avec CSS
- La programmation avec JavaScript
- La manipulation du DOM
- La gestion des données avec LocalStorage
- La création d'un espace administrateur
- La gestion des formulaires
- La navigation entre plusieurs pages

## 🚀 Installation

Aucune installation particulière n'est nécessaire.

Il suffit de télécharger ou cloner le projet puis d'ouvrir `index.html` dans un navigateur.

Pour une meilleure expérience de développement, le projet peut être lancé avec **Live Server** dans Visual Studio Code.
